# She Sells Red Iron — Logo Suite

The I-beam mark replaces the "I" in Iron — red, inline with the wordmark.
Font: Inter 800. Color: #C0392B (red), #111111 (black).

## Files

| File | Use |
|---|---|
| `logo-primary.svg` | Black text, red I-beam — default use on white/light backgrounds |
| `logo-reversed.svg` | White text, red I-beam — for dark backgrounds |
| `logo-red-bg.svg` | White text + white I-beam on red — banners, merch, signage |
| `logo-icon.svg` | I-beam mark only, dark square — favicon, social avatar |
| `logo-icon-red.svg` | I-beam mark only, red square — alternate favicon/avatar |
| `preview.html` | Full preview of all variants in browser |

## Colors
- Red:   `#C0392B`
- Black: `#111111`
- White: `#FFFFFF`
